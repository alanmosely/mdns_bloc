# mdns_bloc 0.3.2

Client factory failures now emit searching followed by error with the original
exception and stack trace. A subsequent search can succeed. This prevents an
uncaught factory failure from leaving discovery stuck in searching.

## Upgrade

Use `mdns_bloc: ^0.3.2` and run `dart pub get` or `flutter pub get`. No API or
stored-data migration is required from 0.3.1. Dart >=3.5 and the existing
Equatable constraints remain supported. Treat `MDnsStatus.error` as a terminal
failed search and allow the user to retry as your normal UI does.

The Android example uses Gradle 9.8.2, AGP 9.5.1 and Kotlin 2.4.21. These are
example-development tools; they do not change the pure-Dart library's SDK floor.

## Artifacts and validation

The pub.dev package archive is the library distribution. A debug Android example
APK and SHA-256 checksums are also attached. The example is for evaluation;
consuming apps should compile and sign their own application.

Release checks cover all 40 package tests on Dart 3.5 and stable, package
analysis/publication dry-run, example analysis/widget tests and Android build.
